In 2026, you can activate Windows using PowerShell by either installing a legitimate product key manually or by using an automated activation script. 
Method 1: Using a Product Key (Official)
If you have a 25-character product key, use these steps to activate your system:
1. Open PowerShell as Administrator: Press Win + X and select Windows Terminal (Admin) or Windows PowerShell (Admin).
2. Install the Key: Type the following command and replace the placeholders with your actual key:
slmgr.vbs /ipk [PRODUCT KEY REDACTED]
3. Activate Online: After the key is installed, run this command to complete online activation:
slmgr.vbs /ato 
Method 2: Using an Automated Activation Script
Popular open-source scripts (such as those from Massgrave) allow you to activate Windows permanently via a single command. 
1. Open PowerShell as Administrator.
2. Run the Command: Copy and paste the following script URL and press Enter:
irm https://get.activated.win | iex
3. Select Activation Type: A menu will appear in the PowerShell window. Press 1 for HWID (Hardware ID) activation, which provides a permanent digital license for your machine. 
Method 3: Recovering an OEM Key
If your computer came with Windows pre-installed, the product key may be embedded in your motherboard. You can retrieve and use it with these steps: 
• Retrieve the Key: Run this command to see the embedded OEM key:
(Get-WmiObject -query 'select * from SoftwareLicensingService').OA3xOriginalProductKey
• Apply the Key: Use Method 1 above to install and activate with the key you just found. 
Note: Always ensure you have a stable internet connection before attempting to activate Windows. For more detailed official information, visit Microsoft Support.
